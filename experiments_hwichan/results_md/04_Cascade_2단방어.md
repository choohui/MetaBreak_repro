# Cascade 2단계 방어 — 깔때기(funnel) 평가 리포트

> **추가 실험**: 약한 신호(어텐션 싱크)를 **1차 게이트**로, 강한 신호(hidden-state norm)를
> **2차 판정**으로 결합한 **2단계 cascade 방어**가 단일 신호보다 실제로 더 잘 잡는지 검증.
>
> 두 단계로 평가:
> - **Tier-1** (`cascade_report_*`) — 기본 feasibility (희소 negative · 동일 데이터 임계값)
> - **Tier-2** (`cascade_tier2_*`) — ⭐ **정직한(honest) 평가** (전체 토큰 negative · train/test 분리)

---

## 1. Cascade 방어란? — 왜 약한 신호를 쓰는가

종합리포트에서 **어텐션 싱크(`sink`) 단독은 약하다**(AUC 0.67~0.85)고 했습니다.
그런데도 cascade에서 1차 게이트로 쓰는 이유:

```
                  ┌─────────────────────┐     ┌──────────────────────────┐
   모든 토큰  →   │ 1차: sink 게이트     │ →   │ 2차: hidden-state norm    │ → 공격 판정
                  │ (값싸고 빠름)        │     │ (강력하지만 무거움)        │
                  │ 쉬운 정상 토큰 제거  │     │ 살아남은 토큰만 정밀 판정  │
                  └─────────────────────┘     └──────────────────────────┘
```

- **1차 게이트**: 싱크 점수로 "명백한 정상 토큰"을 **recall 목표(99%/95%)** 를 지키며 미리 걸러냄
  → `neg_removed`(제거된 정상 비율)만큼 2차로 넘어가는 부담이 줄고, 2차 임계값을 **완화**할 수 있음.
- **핵심 조건**: 두 신호가 **독립적**일수록(상관 `corr` 낮을수록) 깔때기 효과가 커짐.
  싱크는 hidden-state norm과 다른 정보를 보므로(낮은 corr), **결합 시 추가 이득** 기대.

> 즉 "약한 신호도, 강한 신호와 독립적이면, 값싼 1차 필터로서 가치가 있다"는 가설을 검증.

## 2. Tier-1 — 기본 feasibility (`cascade_report_pos{0,1}`)

### 설정
- negative 풀: 메인 연구와 동일한 **희소 샘플** (실험1 = 1,816 / 실험2 = 8,221)
- 임계값을 **동일 데이터에서** 적합 (held-out 아님) → 낙관적 추정치
- 1차 게이트 옵션: `sink@best-layer` vs `sink_layeragg`(layer 최댓값 집계)

### 핵심 관찰

| 실험·위치 | 1차 게이트(AUC) | 대표 결과 (standalone → cascade, TPR@5%) |
|---|---|---|
| 실험1·pos0 | sink L31 (0.735) | hidden_norm: 0.493 → 0.494 (≈ 동일) |
| 실험1·pos1 | sink L1 (0.802) | hidden_norm L20: 0.350 → **0.648** (recall .95) ✅ 큰 향상 |
| 실험2·pos0 | sink L3 (0.849) | value_norm L2: 0.379 → **0.501** ✅, cos_to_D: 0.112 → **0.647** ✅ |
| 실험2·pos1 | sink L25 (0.673) | 대체로 변화 작음 (±0.01) |

- **`sink_layeragg`(집계)보다 단일 best-layer 싱크 게이트가 일반적으로 더 효과적** (neg_removed↑).
- 싱크와 2차 신호의 상관(`corr`)이 낮을수록 향상 폭이 큼 (예: 실험2 cos_to_D corr 0.18 → 큰 이득).
- ⚠️ 단, Tier-1은 임계값을 동일 데이터에 맞춘 **낙관적** 수치 → Tier-2에서 정직하게 재검증.

## 3. Tier-2 — ⭐ 정직한 평가 (`cascade_tier2_pos{0,1}`)

### Tier-1과 무엇이 다른가 (왜 이게 진짜 결과인가)

| 항목 | Tier-1 | **Tier-2 (정직)** |
|------|--------|------------------|
| negative 범위 | 희소 4~6 토큰 샘플 | **프롬프트 전체 본문 토큰** (실배포처럼 "전체 스캔") |
| 임계값 적합 | 동일 데이터 | **train split에서만** 적합, **held-out test**에서 평가 |
| 데이터 분리 | 없음 | **프롬프트 단위 그룹 분리** (변종 누수 방지) |
| negative 풀 크기 | 1,816 / 8,221 | **13,846 / 56,901** (훨씬 현실적·어려움) |

> Tier-2는 "공격/정상의 모든 변종이 train·test에 섞이지 않도록" 같은 질문의
> malicious/mimicked/benign 변종을 한쪽에만 배치 → **과대평가(leakage) 차단**.

### 핵심 결과 — 깔때기가 실제로 효과 있다 (ΔTPR = cascade − standalone)

**🔥 실험2 · pos0 (싱크 게이트 L0, train AUC 0.860) — 가장 극적**

| 2차 신호 (layer) | FPR예산 | standalone TPR | **cascade TPR** | ΔTPR |
|---|:--:|:--:|:--:|:--:|
| value_norm (L2) | 5% | 0.527 | **0.957** | **+0.430** ✅ |
| hidden_norm (L22) | 5% | 0.403 | **0.649** | **+0.247** ✅ |
| output_norm (L30) | 5% | 0.332 | **0.562** | **+0.229** ✅ |
| value_norm (L2) | 1% | 0.401 | **0.459** | +0.058 ✅ |
| output_norm (L30) | 1% | 0.171 | **0.244** | +0.073 ✅ |

> ⚠️ **정직한 주의점**: 5% 예산 행에서 cascade의 실제 test FPR이 0.057~0.070으로
> **예산(5%)을 약간 초과** — train 임계값이 test로 완벽히 전이되지 않음.
> **1% 예산 행은 FPR이 0.010~0.012로 예산 내** → 이쪽이 더 신뢰할 수 있는 이득.

**실험1 · pos1 (싱크 게이트 L2, AUC 0.822) — 일관된 향상**

| 2차 신호 (layer) | FPR예산 | standalone | **cascade** | ΔTPR |
|---|:--:|:--:|:--:|:--:|
| hidden_norm (L20) | 5% | 0.283 | **0.390** | +0.107 ✅ |
| value_norm (L7) | 1% | 0.363 | **0.420** | +0.057 ✅ |
| output_norm (L30) | 5% | 0.279 | **0.297** | +0.019 ✅ |

→ **모든 조합에서 ΔTPR > 0** (FPR도 예산 내). 깔때기가 견고하게 작동.

**실험1 · pos0 / 실험2 · pos1 — 소폭 향상 또는 혼재**

- 실험1·pos0: hidden_norm @5%에서 +0.036~0.042 ✅, 단 value_norm은 소폭 하락(−0.05).
- 실험2·pos1: hidden_norm L24 @1% r.95에서 +0.056 ✅, output_norm은 일부 음수.
- 두 신호 상관이 높거나 싱크 게이트 AUC가 낮은(0.69) 경우 이득이 작아짐 → 가설과 일치.

## 4. 종합 해석 — cascade는 언제 효과 있는가?

| 조건 | 효과 |
|------|------|
| ✅ negative 풀이 크고 현실적 (전체 스캔) | 깔때기 이득 **극대화** (실험2·pos0: +0.43) |
| ✅ 1차 싱크 게이트 AUC가 높음 (≥0.82) | 쉬운 정상 토큰을 많이 제거 → 2차 완화 가능 |
| ✅ 싱크 ↔ 2차 신호 상관(corr) 낮음 | 독립 정보 결합 → 추가 이득 |
| ⚠️ FPR 예산 5%에서 임계값 전이 불완전 | 일부 설정에서 test FPR이 예산 초과 → 보정 필요 |
| ❌ 싱크 게이트 AUC 낮음(0.69) + corr 높음 | 이득 미미 또는 음수 |

### 핵심 메시지

1. ✅ **"약한 신호(어텐션 싱크)도 값싼 1차 게이트로서 가치가 있다"** 는 가설이
   **정직한 held-out 평가에서 입증됨** — 특히 현실적 대규모 negative 환경에서.
2. ✅ **가장 큰 실용적 이득은 전체 프롬프트 스캔 환경**(실험2·pos0, negative 56,901)에서 나타남
   → 실배포 시나리오에 가장 가까운 설정에서 cascade가 빛난다.
3. ⚠️ **임계값 전이가 완벽하지 않음** (특히 5% 예산) → 운영 시 안전 마진을 두거나
   보정(calibration) 필요. **1% 예산 운영점은 안정적**.
4. ✅ **싱크 ↔ hidden-state는 독립적 신호** (corr 0.0~0.6) → 결합의 이론적 근거 확인.

## 5. 권장 배포 구성 (업데이트)

```
[1차: 값싼 싱크 게이트]  sink @ 게이트-layer, recall 99% 목표
   └ 쉬운 정상 토큰 30~50% 제거, 공격은 거의 통과 (recall ~0.99)

[2차: 강한 norm 판정]   value_norm@L2  또는  hidden_norm@L20~24
   └ 살아남은 토큰만 정밀 판정, FPR 1% 예산에서 안정적 운영

         ↑ 두 신호가 독립적이라 결합 시 단일 대비 TPR 향상
         ↑ 전체 프롬프트 스캔(대규모 negative)일수록 이득 큼

[입력단 가드]  experiments_yeonseok (임베딩 L2 거리) — 상호 보완
```

## 6. 한 줄 결론

> **약한 어텐션 신호 + 강한 hidden-state 신호의 2단계 깔때기는,
> 정직한 held-out·전체 스캔 평가에서 단일 신호 대비 탐지율을 끌어올린다**
> (실험2·pos0에서 TPR 0.53 → 0.96). 단, FPR 예산 전이는 운영 시 보정이 필요하다.
