## ⚡ 30초 요약

- **모델**: Llama-3.1-8B-Instruct (33개 hidden layer, dim 4096)
- **분석 토큰 수**: 실험1 약 17,000개 / 실험2 약 60,000개
- **핵심 발견 1** — 모방 토큰(A)·악성 특수 토큰(B)은 **선형 probe로 거의 완벽하게(ROC-AUC ≈ 1.0)** 정상 토큰과 구분된다.
- **핵심 발견 2** — 단일 특성(feature) 임계값만으로도 **AUC 0.90~0.95** 수준의 탐지가 가능하다 (가장 강한 신호: `output_norm`, `hidden_norm`, `value_norm`).
- **핵심 발견 3** — 어텐션 싱크(`sink`) 단독 신호는 hidden-state 기반 신호보다 **약하다** (AUC 0.67~0.80).
- **핵심 발견 4** — 모방 토큰(A)은 실제 시스템 특수 토큰(D)을 **표면적으로는 흉내 내지만**, 내부 기하 구조에서는 끝까지 D와 다른 위치에 머문다 → **내부 신호로 탐지 가능한 이유**.
- **핵심 발견 5 (🆕 cascade)** — 약한 싱크 신호를 1차 게이트로 둔 **2단계 깔때기**가, 정직한 held-out·전체 스캔 평가에서 단일 신호 대비 탐지율을 끌어올린다 (실험2·pos0: TPR **0.53 → 0.96**).

> 자세한 수치와 해석은 **[00_종합리포트.md](00_종합리포트.md)**,
> cascade 결과는 **[04_Cascade_2단방어.md](04_Cascade_2단방어.md)** 참고.
